## 安装Livox-SDK2

[Livox-SDK2 github仓库](https://github.com/Livox-SDK/Livox-SDK2)
### Livox-SDK2介绍
Livox-SDK2 是为Livox官方为其雷达产品如HAP和Mid-360编写的软件开发工具(Software Development Kit)。Livox-SDK2基于C/C++语言且遵守Livox-SDK2通信协议，并且提供了容易使用的C风格的API，使用Livox-SDK2可以使我们快速的连接Livox雷达和获取点云数据

### Livox-SDK2通信协议
通信协议包含了控制命令和数据格式，文档如下
[Mid-360通信协议](https://livox-wiki-cn.readthedocs.io/zh-cn/latest/tutorials/new_product/mid360/mid360.html)

### 安装
首先安装cmake
```bash
sudo apt install cmake
```

然后克隆github仓库，并编译安装
```bash
git clone https://github.com/Livox-SDK/Livox-SDK2.git
cd ./Livox-SDK2/
mkdir build
cd build
cmake .. && make -j
sudo make install
```

生成的动态库和静态库文件安装在`/usr/local/lib`目录下，头文件在`/usr/local/include`目录下

![[Pasted image 20260205003126.png]]

要删除的话执行以下命令

```bash
sudo rm -rf /usr/local/lib/liblivox_lidar_sdk_*
sudo rm -rf /usr/local/include/livox_lidar_*
```

### 配置环境变量
添加库文件的路径至`LD_LIBRARY_PATH`环境变量,首先使用vim/nano打开.bashrc

```bash
vim ~/.bashrc
```

然后在最后一行添加`/usr/local/lib/`路径

```bash
export LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH
```

然后保存退出,使用下面的命令让其立即生效

```bash
source ~/.bashrc
```

验证路径

```bash
echo $LD_LIBRARY_PATH
```
![[Pasted image 20260205005333.png]]
出现`/usr/local/lib/`路径说明添加成功

### 第一次连接雷达

首先给雷达上电,通过有线网口连接电脑.(如果雷达在振动说明就是在正常工作)
#### 修改本机ip地址

在"设置->网络->有线->IPV4"中更改IPV4方式为手动,地址改为"192.168.1.xx"(xx为任意的两位数,我这里给的是50),子网掩码改为"255.255.255.0",网管改为"192.168.1.1"(或者可以不填)

![[Pasted image 20260205095929.png]]

#### 修改雷达config文件

mid-360的固定地址为192.168.1.1xx(xx为雷达的sn码后两位),可以先ping一下这个地址测试联通性
```bash
ping 192.168.1.1xx
```
![[Pasted image 20260205100614.png]]

如果看到有数据就证明连接上了.

然后修改config文件,congif文件在`~/Livox-SDK2/samples/livox_lidar_quick_start`下,修改mid360_config.json的host_ip为本机ip,添加lidar_ip
![[Pasted image 20260205103505.png]]

运行`livox_lidar_quick_start`例程,确保自己在路径`~/Livox-SDK2/build/samples/livox_lidar_quick_start`下

```bash
./livox_lidar_quick_start ../../../samples/livox_lidar_quick_start/mid360_config.json
```
![[Pasted image 20260205102818.png]]

出现该窗口代表成功通过`livox_lidar_quick_start`获取到了mid360的数据

## 安装livox_ros_driver2

[livox_ros_driver2 github仓库](https://github.com/Livox-SDK/livox_ros_driver2)
### livox_ros_driver2介绍
(源自官方)
Livox ROS Driver 2 是用来连接 Livox 激光雷达的第二代驱动包，同时支持 ROS1 和 ROS2，其中官方推荐的 ROS1 版本是 Noetic，推荐的 ROS2 版本是 Foxy 或 Humble

Livox ROS Driver 2 只是一个官方提供的测试/示例驱动，适合在研发和调试阶段使用；如果你要用在真正的产品或量产系统里，应该基于它的源码自行修改和优化，做成符合你自己项目要求的稳定驱动，而不是直接原样拿去上量产

### 安装

前备条件:安装Ubuntu 22.04；安装ROS2及Colcon

#### 克隆仓库
```bash
mkdir livox_ws/src && cd livox_ws/src
git clone https://github.com/Livox-SDK/livox_ros_driver2.git 
```

#### 构建仓库

构建仓库前一定记得修改配置文件,修改在`/home/yummy/livox_ws/src/livox_ros_driver2/config`路径下`MID360_config.json`文件,将host_net_info的ip修改为本机的ip,将lidar_configs里的ip修改为雷达的ip

![[Pasted image 20260205104625.png]]

确保自己在`livox_ws/src`路径
```bash
source /opt/ros/humble/setup.sh
./build.sh humble
```

#### 启动驱动

启动驱动命令
```bash
source ../../install/setup.sh
ros2 launch livox_ros_driver2 [launch file]
```
- **[launch file]** : 是你想要使用的 ROS2 启动文件; 在文件夹 'launch_ROS2' 中包含了一些可供参考的启动文件示例
官方给的launch file有好多个,其中为mid360准备的有两个
- rviz_MID360.launch:连接到MID360 LiDAR设备,发布pointcloud2格式数据,自动加载rviz
- msg_MID360.launch:连接MID360激光雷达设备,发布Livox定制的点云数据

例如,启动rviz_MID360.launch
```bash
source ../../install/setup.sh
ros2 launch livox_ros_driver2 rviz_MID360.launch
```

跳出窗口

![[Pasted image 20260205105323.png]]

启动官方驱动完成,可以查看点云信息

# Fast_LIO_ROS2算法

## 克隆仓库并编译

```bash
cd livox_ws/src
git clone https://github.com/Ericsii/FAST_LIO.git --recursive
cd ..
sudo apt install python3-rosdep2
rosdep update
rosdep install --from-paths src --ignore-src -y
colcon build --symlink-install
```

说明:
1. `git clone https://github.com/Ericsii/FAST_LIO.git --recursive`后面的`--recursive`指令不能省略,否则少安装子模块. 如果真的忘记加可以使用`git submodule update --init`指令补充安装子模块
2. python3-rosdep2是一个ROS 生态里的依赖管理工具，会根据包里的 `package.xml`，识别需要哪些系统库、ROS 包等依赖。安装rosdep后需要先`rosdep update`一下,再使用命令`rosdep install --from-paths src --ignore-src -y`安装依赖文件
3. `colcon build --symlink-install` 的意思是：用 colcon 编译当前 ROS 2 工作空间，并且在安装时用“符号链接（软链接）”而不是复制文件。这样修改 `src` 里的 Python 脚本、launch 文件、配置文件等，通常不需要重新 build 就能生效，开发迭代会更快。

## 运行Fast-LIO算法

首先第一个窗口运行驱动
```bash
cd livox_ws/

source install/setup.bash

ros2 launch livox_ros_driver2 msg_MID360_launch.py
```

然后新建一个窗口运行mapping算法

```bash
cd livox_ws/

source install/setup.bash

ros2 launch fast_lio mapping.launch.py
```
