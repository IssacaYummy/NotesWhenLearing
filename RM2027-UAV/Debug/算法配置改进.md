
### **5.1 算法配置改进（立即可用，已在 6 个数据包上验证通过）**

#### **(1) OpenVINS 配置修改**

- **修改 estimator_config.yaml**：

```yaml
calib_cam_extrinsics: false   # 原为 true，必须关闭！防止静止/悬停时双目基线被破坏
calib_cam_intrinsics: false   # 原为 true，必须关闭！
calib_cam_timeoffset: false   # 原为 true，建议关闭或仅在充分激励下开启

try_zupt: true                # 开启起始零速修正，允许地面静止立即初始化 (wait_for_jerk=false)
zupt_only_at_beginning: true  # 仅在起飞前使用 ZUPT，避免空中悬停误触发
init_window_time: 1.0         # 原为 2.0，缩短为 1.0s 加快初始化
init_imu_thresh: 1.5          # 原为 1.0
init_dyn_use: true            # 开启空中/带桨振动动态初始化作为兜底

up_msckf_sigma_px: 2          # 原为 1，放宽至 2 px 适应机身振动
up_msckf_chi2_multipler: 2    # 原为 1，放宽卡方门限防止误拒视觉观测
up_slam_sigma_px: 2           # 原为 1
up_slam_chi2_multipler: 2     # 原为 1
```

- **修改 kalibr_imu_chain.yaml**：

```yaml
accelerometer_noise_density: 0.08   # 原为 0.007545，放大至匹配旋翼振动水平
accelerometer_random_walk: 0.002
gyroscope_noise_density: 0.005      # 原为 0.000824
gyroscope_random_walk: 0.0002
```
#### **(2) VINS-Fusion 配置修改**

- **修改 stereo_imu_config.yaml**：

```yaml
acc_n: 0.20          # 原为 0.02134，放大以吸收旋翼高频振动
gyr_n: 0.02          # 原为 0.00233
acc_w: 0.0005        # 原为 0.01414，大幅收紧偏置随机游走，消除地面静止姿态零空间漂移！
gyr_w: 0.00005       # 原为 0.001414
```
