# 更改中文和中文输入法

## 1. 更改中文

先安装中文语言包和中文字体：

```bash
sudo apt update
sudo apt install language-pack-zh-hans language-pack-zh-hans-base \
  language-pack-gnome-zh-hans language-pack-gnome-zh-hans-base \
  fonts-noto-cjk
```

然后生成并设置中文 Locale：

```bash
sudo locale-gen zh_CN.UTF-8
sudo update-locale LANG=zh_CN.UTF-8 LANGUAGE="zh_CN:zh:en_US:en"
```

注销当前 XFCE 会话并重新登录。重新登录后，菜单、文件管理器、设置等大部分界面应该变成中文。

如果想通过图形界面设置，也可以运行：

```
gnome-language-selector
```

如果提示命令不存在：

```
sudo apt install language-selector-gnome
```

打开后选择“汉语（中国）/ Chinese (China)”，然后重新登录。

重新登陆后一定要选择保留旧的文件目录名称，因为英文更方便

## 2. 更改中文输入法

中文输入法推荐 Fcitx5。安装：

```bash
sudo apt install fcitx5 fcitx5-chinese-addons fcitx5-config-qt \
  fcitx5-frontend-gtk3 fcitx5-frontend-qt5
```

然后让系统使用 Fcitx5：

```bash
im-config -n fcitx5
```

建议再配置 XFCE 会话环境。在 `~/.xprofile` 中加入：

```bash
cat >> ~/.xprofile <<'EOF'
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
EOF
```

之后注销并重新登录。

登录后运行：

```bash
fcitx5-configtool
```

在“输入法”中添加：

```
拼音 / Pinyin
```

# 安装并使用ssh
## 1. 在被远程的电脑上开启ssh

```bash
sudo apt update
sudo apt install openssh-server tmux
sudo ssh-keygen -A
sudo systemctl enable --now ssh
systemctl status ssh --no-pager
```
![[PixPin_2026-10-24_09-49-55.png]]

看到 `active (running)`，表示 SSH 服务已启动

查看当前用户名和 IP 
```bash
whoami
hostname -I
```

检查防火墙并放行
```bash
sudo ufw status
sudo ufw allow OpenSSH
```

## 2. 连接被远程的电脑
确认你和被远程的电脑在同一个局域网，以OrangePi为例
```bash
ssh orangepi@192.168.5.109
```

首次连接会询问是否信任设备。

![[Pasted image 20261024100028.png]]

可以在 Orange Pi 上查看主机指纹：

```
sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

![[PixPin_2026-10-24_10-00-44.png]]

与连接提示中的 ED25519 指纹核对后接受，再输入 **Orange Pi 用户的密码**。

出现下面的页面即为连接成功
![[Pasted image 20261024100112.png]]

## 3. 使用vscode进行远程编辑代码

搜索拓展 Remote -SSH 并安装，安装后按`Ctrl+Shift+P`，选择`Remote-SSH: Connect to Host`，添加需要远程连接的主机，输入
```bash
ssh orangepi@192.168.5.109
```
选择一个文件夹存储配置文件
![[Pasted image 20261024101105.png]]
保存后再次按`Ctrl+Shift+P`，选择`Remote-SSH: Connect to Host`，选择刚才添加的主机连接，并输入密码

连接后选择打开文件夹，打开OrangePi上面的项目目录打开即可编辑
