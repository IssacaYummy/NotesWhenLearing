通过遥控器控制无人机一般要经过两层协议，一个是`遥控器->接收机`的协议，另一个是`接收机->飞控`的协议。

### 第一层：遥控器 ↔ 接收机的无线协议

| 无线协议                      | 常见品牌/系统                          | 频段              | 特点                |
| ------------------------- | -------------------------------- | --------------- | ----------------- |
| **WFLY FHSS**             | 天地飞 ET08/ET08A 等                 | 2.4 GHz         | 成本低、你已经有设备，但生态较封闭 |
| **ExpressLRS / ELRS**     | RadioMaster、BETAFPV、Happymodel 等 | 2.4G / 868/915M | 开源、低延迟、小型接收机非常多   |
| **TBS Crossfire**         | TBS                              | 868/915 MHz     | 成熟、远距离、可靠         |
| **FrSky ACCST / ACCESS**  | FrSky                            | 2.4 GHz         | 老牌航模生态            |
| **FlySky AFHDS 2A**       | 富斯                               | 2.4 GHz         | 便宜，固定翼/入门航模较常见    |
| **Spektrum DSMX**         | Spektrum                         | 2.4 GHz         | 欧美航模常见            |
| **Futaba FASST / T-FHSS** | Futaba                           | 2.4 GHz         | 稳定成熟，但价格高         |

## 第二层：接收机 ↔ 飞控协议

| 接口协议     | 线数    | 特点          |
| -------- | ----- | ----------- |
| PWM      | 每通道一根 | 最传统，一个通道一根线 |
| PPM      | 1     | 多通道复用，比较老   |
| SBUS     | 1     | 多通道数字串行     |
| iBUS     | 1     | FlySky 常见   |
| F.Port   | 1     | FrSky 单线双向  |
| SRXL2    | 1     | Spektrum    |
| **CRSF** | TX+RX | 双向、低延迟、遥测   |
