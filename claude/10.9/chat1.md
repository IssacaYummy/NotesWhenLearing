# 李群和李代数

## 1. 先建立直觉：为什么需要它们？

想象无人机在空中的姿态（朝向）。你想做两件事：

- **表示姿态**：用旋转矩阵、四元数等。
- **优化姿态**：比如 VIO 里要根据误差调整姿态，让重投影误差最小。

问题来了：**旋转不能随便加减。**

两个旋转矩阵相加，结果通常不再是旋转矩阵（不再正交、行列式不为 1）。而优化算法（梯度下降、高斯牛顿）恰恰需要"当前值 + 小增量"这种加法。

**李群 + 李代数的思路：** 旋转本身住在一个"弯曲的世界"里（不能加减），但在每个点附近，这个弯曲世界可以被一个"平坦的世界"近似（可以随意加减）。在平坦世界里做加法、求导，再映射回弯曲世界。

类比：地球表面是弯曲的（李群），但在你脚下一小块范围内可以当成平面（李代数）。你在平面地图上做加减计算很方便，最后再贴回球面。

## 2. 术语中英对照

| 英文 | 中文 | 实际含义 |
|---|---|---|
| Group | 群 | 一个集合 + 一种运算，满足封闭、结合、有单位元、有逆元 |
| Lie group | 李群 | 同时是"光滑曲面"的群，可以求导 |
| Lie algebra | 李代数 | 李群在单位元处的切空间（平坦的向量空间） |
| Exponential map | 指数映射 | 李代数 → 李群（平坦 → 弯曲） |
| Logarithm map | 对数映射 | 李群 → 李代数（弯曲 → 平坦） |

## 3. 什么是群（Group）

群是一个集合加一个运算。以三维旋转为例，所有三维旋转矩阵构成集合，运算是矩阵乘法：

- **封闭**：两个旋转相乘仍是旋转
- **结合**：(R₁R₂)R₃ = R₁(R₂R₃)
- **单位元**：单位矩阵 I（"不转"）
- **逆元**：Rᵀ（反向转回去）

注意：**旋转的乘法一般不可交换**（R₁R₂ ≠ R₂R₁），先绕 x 转再绕 y 转，和反过来结果不同。

## 4. 李群（Lie Group）

李群 = 群 + 光滑（连续可微）。机器人中最常用的两个：

- **SO(3)**：三维旋转群，3 个自由度。矩阵 R 满足 RᵀR = I，det(R) = 1。
- **SE(3)**：三维刚体变换群（旋转 + 平移），6 个自由度。用 4×4 矩阵 T = [R t; 0 1] 表示。

它们都是**有约束**的矩阵：SO(3) 用 9 个数表示，却只有 3 个自由度。这就是"弯曲"的来源——数在一个低维曲面上，不能随意改。

## 5. 李代数（Lie Algebra）

在单位元（"不转"这一点）附近取切空间，就得到李代数。

**SO(3) 的李代数 so(3)**：是所有 3×3 反对称矩阵，每个对应一个三维向量 φ = (φ₁, φ₂, φ₃)：

$$\phi^\wedge = \begin{bmatrix} 0 & -\phi_3 & \phi_2 \\ \phi_3 & 0 & -\phi_1 \\ -\phi_2 & \phi_1 & 0 \end{bmatrix}$$

**物理意义**：向量 φ 就是**旋转向量（轴角）**，方向是旋转轴，长度是旋转角度。它是 3 维的、无约束的，可以任意加减。

**SE(3) 的李代数 se(3)**：6 维向量 ξ = (ρ, φ)，前三维对应平移相关，后三维对应旋转。

## 6. 指数映射和对数映射：两个世界的桥梁

**指数映射**把李代数变成李群：

$$R = \exp(\phi^\wedge)$$

展开后就是**罗德里格斯公式（Rodrigues' formula）**：

$$R = \cos\theta\, I + (1-\cos\theta)\, nn^T + \sin\theta\, n^\wedge$$

其中 θ = ‖φ‖，n = φ/θ。

**对数映射**反过来：R → φ。

这就是"平坦世界 ↔ 弯曲世界"的转换器。

## 7. 在优化里怎么用（核心用途）

假设要优化姿态 R，使误差 e(R) 最小。直接对 R 加增量会破坏约束。做法是：

1. 在李代数里定义一个小增量 δφ（3 维，随便加减）
2. 通过指数映射转成小旋转 exp(δφ^)
3. 更新：R ← exp(δφ^) · R（乘法，保持在群上）
4. 对 δφ 求导（即**扰动模型，perturbation model**），得到雅可比矩阵

**好处**：优化变量是 3 维（最小参数化，无冗余），没有约束，也没有奇异点（欧拉角有万向锁，Gimbal lock）。

**代价**：需要推导李代数上的雅可比，公式比普通向量复杂；还要小心左乘/右乘扰动的约定，不同论文和库可能不同。

## 8. 与无人机项目的关系

在 VIO/SLAM 中几乎处处用到：

- **位姿表示**：相机/IMU 位姿属于 SE(3)
- **后端优化**（BA、因子图）：用 se(3) 增量更新位姿（g2o、Ceres、GTSAM 都是这样做的）
- **IMU 预积分（preintegration）**：积分的是旋转，需要在 SO(3) 上做，并推导误差对 bias 的雅可比
- **EKF/滤波器**：姿态误差用 so(3) 向量表示（误差状态卡尔曼滤波，ESKF）

## 9. 一句话总结

> **李群**是"有约束、弯曲、不能加减"的位姿空间（SO(3)/SE(3)）；**李代数**是它在某点附近的"无约束、平坦、可加减"的线性近似；**指数/对数映射**是两者之间的桥梁，让我们能在优化中安全地处理旋转。

推荐的顺序：先掌握 SO(3) 的 so(3)、指数映射和罗德里格斯公式，再理解左扰动/右扰动的雅可比，最后扩展到 SE(3)。需要的话，我可以接着用一个具体数值例子，手算一遍"旋转向量 → 旋转矩阵"，或者讲清楚扰动模型的雅可比推导。
