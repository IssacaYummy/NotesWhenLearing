|   |   |
|---|---|
|`const_cast <MyClass*>(value)`|用来改变value的常量性|
|`dynamic_cast <MyClass*>(value)`|用来把一种类型的对象指针安全地强制转换为另一种类型的对象指针<br><br>注：如果value的类型不是一个MyClass类（或MyClass的子类）的指针，这个操作符将会返回NULL|
|`reinterpret_cast<T>(value)`|在不进行任何实质性转换的情况下，把一种类型的指针解释为另一种类型的指针或者把一种整数解释为另一种整数|
|`static_case<T>(value)`|用来进行强制类型转换而不做任何运行时检查，老式强制类型转换操作的替代品|
