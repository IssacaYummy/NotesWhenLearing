## 模块化

### 头文件

只用一个源代码来保存程序的全部代码是可行的，但会给编辑修改工作带来不便

我们可以借助C++的预编译器和编译器的能力把一个复杂的应用程序划分为多个不同的文件，而仍保持它在内容和功能上的完整

C++预处理器的#inclulde 指令提供了一种能够让编译器在编译主程序时把其他文件的内容包括进来的机制

头文件的基本用途是提供必要的函数声明和类声明。比如string头文件就定义了字符串应该如何创建和使用

头文件又分为系统头文件和自定义头文件

系统头文件定义的是系统级功能，使得C++代码可以在某种特定的系统上运行

系统头文件的另一个重要作用就是保证C++代码的可移植性，确保同样的C++代码在不同的操作系统上做同样的事

例如为Mac定义的cout和为windows定义的cout做的事情一样，但内部的具体实现可能不一样

在#include指令里，系统头文件的文件名要放在尖括号<>里给出，这是告诉编译器：应该到标准的地点寻找这个文件

自定义头文件的文件名要放在双引号里给出

头文件是以 `.h` 为拓展名的标准文本文件。

一般情况下，都应该把自定义的头文件和其余的程序文件放在同一个子目录里

与标准的C++源代码文件相比，在头文件里应该使用更多的注释

应该在注释里说明的内容包括：

创建日期、文件用途、创建者姓名、最后一次修改日期、有什么限制和前提条件等等

### C预处理器

利用C++预处理器，我们可以让头文件只在这个类还没有被声明的情况下才声明它

预处理器条件指令

|   |   |
|---|---|
|指令|说明|
|#if|如果表达式为真，执行代码|
|#else|如果前面的#if表达式为假，执行代码|
|#elif|相当与#elseif|
|#endif|用来标志一个条件指令的结束|
|#ifdef|如果本指令所引用的定义已存在，执行代码|
|#ifndef|如果本指令所引用的定义不存在，执行代码|

```C++
#ifndef HEADER_H
#define HEADER_H
//一些代码
#endif
```

如果HEADER_H没有被定义，这里就会先定义HEADER_H，然后执行后面的语句；如果已经被定义则会跳过后面的所有语句，并在#endif结束条件指令。

这样操作避免了头文件重复引入，以及头文件中的内容被重复声明

作为一种固定模式，这里使用的常量名通常与相应的文件名保持一致，把`.`替换成`_`

## 命名空间

1. 定义
    

命名空间的定义需要使用namespace关键字，后面跟上一对{}，{}内包含了命名空间的成员

命名空间中可以包含变量函数类型

```C++
namespace example
{
        int a = 10;
        int arr[10] = { 0 };

        int sum(int a, int b)
        {
                return a + b;
        }

        struct N
        {
                int i = 0;
        };
}

int main()
{

        return 0;
}
```

2. 注意：
    

- 命名空间不可以定义在局部作用域
    
- 命名空间可以嵌套
    
- 统一工程中允许存在多个相同的命名空间，编译器最后会将其合并成一个命名空间，不会报错；但在同一命名空间中不允许存在相同变量/函数/类型，否则会报错
    
- 允许存在未命名的命名空间，
    

这种命名空间没有名称，就不能使用using声明和using编译指令来使他在其他位置也可用，从某方面来看，他和全局变量相似，具有内部链接性，也就是不能在命名空间所属文件以外的地方使用该命名空间里面的成员。（直接将其当做全局变量，直接使用即可，但是有名的命名空间必须跟上::或者使用using才可以访问）

一个命名空间的定义就相当于给其中的成员围上了栏杆，没有允许的话，任何人都不能访问其中的变量，不同命名空间里面即使是相同的变量名，但是本质是两个变量

### 命名空间的使用

- **::** 叫做作用域限定符
    
- using也是属于C++的关键字
    

命名空间的使用有三种方式：

1. 加命名空间名称及作用限定符
    

```C++

int main()
{
        printf("%d\n", example::a);
        return 0;
}
```

2. 使用 using将命名空间的某个成员引入
    

```C++
using example::a;
int main()
{
        printf("%d", a);
        return 0;
}
```

3. 使用“using namespace 命名空间名称”引入
    

```C++
using namespace example;
int main()
{
        printf("%d\n", a);
        printf("%d", sum(1, 2));
        return 0;
}
```

注意：

1. using声明和using编译指令可以使用在全局，此时全局展开，也可在局部使用，此时仅仅在局部有用
    
2. using声明和using编译指令在局部使用的时候，和其他的局部变量一样，会覆盖全局的同名变量
