### 访问控制

C++提供的一种用来保护类的方法和属性的手段

这里的保护的意思是对谁可以调用某个方法和访问某个属性加上一个限制。如果某个对象试图调用一个他无权访问的函数，编译器将报错

总共有三个级别

| 级别        | 允许谁来访问     |
| --------- | ---------- |
| public    | 任何代码       |
| protected | 这个类本身和他的子类 |
| private   | 只有这个类本身    |

使用访问级别保护类里的属性和方法：

在类的某个地方写出一个访问级别并在其后加上一个冒号，从那个地方开始往后的所有方法和属性都将受到相应的保护，直到遇到下一个访问级别或者到达这个类的末尾为止

编写时最好按照public、protected、private的顺序来写

### 关于从基类继承来的方法和属性的保护：

class Pig : public Animal { ... };

C++不仅允许你在类里定义方法和属性实施访问控制，还允许你控制子类可以访问基类里的哪些方法和属性

- public: Animal前的public是在告诉编译器：继承的方法和属性的访问级别不发生任何改变，即public仍可以被所有代码访问，protected只能由基类的子类访问，private则只能由基类本身访问
    
- protected: 如果基类原来的访问级别是public的话，改为protected。这将使得这个子类外部的代码无法通过子类去访问子类从基类中继承的public中的元素
    
- private：告诉编译器从基类继承来的每一个成员都当成private来对待，这意味着只有这个子类可以使用它从基类继承来的元素
    

一般只用public即可
