首先从类开始，类是一个模型。当我们为这个类创建实例的时候，也就创建了对象本身。这个过程与定义和使用结构体类似，但是更具有拓展性和前瞻性

与结构最显著的区别：对象的内部可以有变量和函数，而结构通常只由各种变量组成

要创建对象，首先要创建一个简单对象的模型——类

类（class）就像是一份蓝图，他决定一个对象将是什么样的（具备什么样的属性、功能）

```C++
class MyFirstClass
{

};
```

注意：类名的第一个字母习惯上采用大写；类声明末尾和结构一样必须要有一个分号

类由变量和函数组成，对象将使用那些变量来储存信息，调用那些函数来完成操作。所以人们将类里的变量称为属性，函数称为方法。但他们的本质并没有区别

下面的代码示例创建car类

```C++
#include <iostream>

class car
{
public:
    std::string color;
    std::string engine;
    float gas_tank;
    unsigned int Wheel;

    void fill_tank( float liter );
    void running(void);

};

void car::fill_tank( float liter )
{
    gas_tank += liter;
}

int main()
{
    char i;
    car mycar;

    mycar.color = "White";
    mycar.engine = "V8";
    mycar.Wheel = 4;
    mycar.gas_tank = 0;

    mycar.fill_tank(1);
    mycar.running();
    return 0;
}
```

注意：

1. 方法的定义通常安排在类 声明的后面；
    
2. 方法定义时使用了域解析操作符（：：），告诉编译器这个方法存在于何处，或者说是属于哪一个类;
    
3. 在程序中使用点操作符访问对象的属性和方法
    
4. 类的声明一般放入.h文件中，类中函数的定义一般放入.cpp文件中
    
5. C++允许在类里声明常量,但不允许对它进行赋值,绕开这一限制的方法是创建一个静态常量
    
6. 类似与结构可以在声明某个类的同时立刻创建一些该类的对象
    
7. 可以使用 " = " 将一个对象中的属性赋值给同一个类的对象
