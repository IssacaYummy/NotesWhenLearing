多态性时面对对象程序设计的重要特征之一

多态的字面意思是“多种形态”。在 C++ 的上下文中，它指的是**同一个操作（通常是函数调用）作用于不同的对象，可以产生不同的行为**。

简单来说，就是 “**一个接口，多种实现**” 。你使用一个统一的接口（比如一个基类的函数名），但具体执行哪个实现，取决于调用该接口的对象的实际类型。

## C++中多态的分类

C++主要支持两种类型的多态：

1. 编译时多态（静态多态）
    
    1. 实现方式：函数重载、运算符重载、模板
        
    2. 特点：在程序编译阶段，编译器根据传递的参数类型、数量或类来确定具体调用哪个函数。绑定（Binding）发生在编译期。
        
2. 运行时多态（动态多态）
    
    1. 实现方式：虚函数和继承体系
        
    2. 特点：在程序运行阶段，根据指针或引用所指向的实际对象类型来决定调用哪个函数。绑定发生在运行期。
        

## 比较

|   |   |   |
|---|---|---|
|特性|编译时多态（静态）|运行时多态（动态）|
|实现机制|函数重载、模板|虚函数、继承|
|绑定时间|编译时|运行时|
|速度|更快（无额外开销）|稍慢（需要查vtable）|
|灵活性|较低（基于类型）|极高（基于对象）|
|关键关键字|template, typename|virtual, override, final|
|核心应用|通用编程（STL）|面向对象设计、框架设计|
