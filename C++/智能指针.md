智能指针类似于常规指针，但是他负责自动释放所指向的对象
## 1.auto_ptr(已弃用)
auto_ptr是一个早期的智能指针，当受管理对象超出作用域会自动删除

> 该指针在C++11已弃用，在C++17已删除
## 2. unique_ptr
`unique_ptr`一次只能储存一种指针，无法复制`unique_ptr`，只能通过`move()`方法将对象的所有权转移给另一个`unique_ptr`

![][https://media.geeksforgeeks.org/wp-content/uploads/20250402152108622799/unique-pointer-in-cpp.webp]
```cpp
auto robot = std::unique_ptr<Robot>();
// std::unique_ptr<Robot> robot2 = robot; // 错误！不能复制
std::unique_ptr<Robot> robot2 = std::move(robot); // 可以，转移所有权

```
## 3. shared_ptr
多个指针可以共享同一个对象，通过引用计数追踪有多少个指针指向它，当最后一个`shared_ptr`被销毁时，对象才释放
```cpp
std::shared_ptr<Data> data1(new Data());
std::shared_ptr<Data> data2 = data1; // 引用计数变为 2
// data1 和 data2 都指向同一个对象
// 只有当两者都销毁后，Data 对象才释放

```
## 4. weak_ptr
特点是不增加引用计数，用于打破循环引用

## 使用语法
以`auto robot = std::make_unique<Robot>();`为例
- `std::make_unique`是C++标准库提供的模板类，表示独占所有权的智能指针
- `<Robot>`：尖括号里的模板参数，告诉这个编译器这个指针专门用来指向`Robot`类型的对象
- `robot`：变量名
