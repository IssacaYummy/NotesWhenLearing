# 构造器

构造器是类里的一种特殊的方法(函数)

构造器和通常方法(函数)的主要区别:

1. 构造器的名字必须和他所在的类的名字一样
    
2. 系统在创建某个类的实例时会第一时间调用这个类的构造器,对类的属性进行初始化
    
3. 构造器永远不会返回任何值
    

创建构造器,首先把它的声明添加到类里

```C++
class car
{
    car(void);
};
```

注意大小写保持一致,在结束声明之后开始定义构造器本身

```C++
car::car(void)
{
    color = "White";
    engine = "v8";
    wheel = 4;
    gas_tank = FULL_GAS;
}
```

数组可以是任何一种数据类似,当然也包括对象,所以我们也可以定义一个对象数组

```C++
car mycar[10];
```

调用语法仍然是mycar[x].running;

每个类至少有一个构造器,如果你没有在类里定义一个构造器,编译器就会使用如下语法帮你定义一个:

ClassName::ClassName( ){ }

这是一个没有代码内容的空构造器,除此之外,编译器还会替你创建一个副本构造器(CopyConstructor)

# 析构器

在销毁一个对象时,系统会调用析构器用来完成清理内存的操作

析构器有着和构造器/类一样的名字,只是前面多了一个波浪符"~"前缀

```C++
class car
{
    car(void);
    ~car();
}
```

析构器不返回任何值也不带任何参数,所以析构器的声明永远是如下格式:

~ClassName();

某个类的构造器申请了一块内存,我们就必须在析构器里释放那块内存
