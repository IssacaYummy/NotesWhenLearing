# 静态属性

使用情景：需要的功能或数据不属于某个对象，而是属于整个类的

C++允许我们把一个或多个成员声明为只属于某个类，而不是属于该类的对象

方法就是在该类中创建静态属性或静态方法，在声明前加上static关键字

这么做的好处是时是程序员可以在没有创建任何对象的情况下调用有关的函数（方法），且能让有关的数据（属性）能够在该类的所有对象间共享

示例代码

```C++
#include <iostream>

class Pet
{
public:
    Pet(std::string theName);
    ~Pet();

    static int getCount();
protected:
    std::string name;
private:
    static int count;
};

int Pet::count = 0;     // 分配内存 初始化为0

class Dog : public Pet
{
public:
    Dog(std::string theName);
    ~Dog();
};

class Cat : public Pet
{
public:
    Cat(std::string theName);
    ~Cat();
};

Pet::Pet(std::string theName)
    : name(theName)
{
    count++;
    std::cout << "A pet named " << name << " is created!\n" << std::endl;
}

Pet::~Pet()
{
    count--;
    std::cout << "A pet named " << name << " is destroyed!\n" << std::endl;
}

int Pet::getCount()
{
    return count;
}

Dog::Dog(std::string theName)
    : Pet(theName)
{
    std::cout << "A dog named " << name << " is created!\n" << std::endl;
}

Dog::~Dog()
{
    std::cout << "A dog named " << name << " is destroyed!\n" << std::endl;
}

Cat::Cat(std::string theName)
    : Pet(theName)
{
    std::cout << "A cat named " << name << " is created!\n" << std::endl;
}

Cat::~Cat()
{
    std::cout << "A cat named " << name << " is destroyed!\n" << std::endl;
}

int main()
{
    Dog dog("Tom");
    Cat cat("Kitty");

    std::cout << "There are " << Pet::getCount() << " pets now. \n\n" << std::endl;

    {
        Dog dog2("Bob");
        Cat cat2("Lily");
        
        std::cout << "There are " << Pet::getCount() << " pets now. \n\n" << std::endl;
    }

    std::cout << "There are " << Pet::getCount() << " pets now. \n\n" << std::endl;

    return 0;
}
```

在C和C++中，`static`关键字有多种用途，但其核心作用是**控制变量或函数的存储期（生命周期）和可见性（作用域）**。以下是详细解释：

下面是deepseek生成的C++和C语言中的static关键字的作用

### 一、C语言中的`static`

#### 1. **修饰局部变量（函数内部）**

- **作用**：将局部变量从**自动存储期**改为**静态存储期**。
    
- **特点**：
    
    - 变量在程序启动时初始化一次（只初始化一次），函数调用结束后**不销毁**，保留其值。
        
    - 作用域仍局限于函数内部，但生命周期持续到程序结束。
        
- **示例**：
    
    ```C
    void counter() {
        static int count = 0; // 只初始化一次
        count++;
        printf("Count: %d\n", count);
    }
    int main() {
        counter(); // 输出 Count: 1
        counter(); // 输出 Count: 2（保留上次的值）
        return 0;
    }
    ```

#### 2. **修饰全局变量或函数（文件内部）**

- **作用**：将全局变量或函数的链接属性从**外部链接**改为**内部链接**。
    
- **特点**：
    
    - 被`static`修饰的全局变量/函数仅在**当前源文件内可见**，其他文件无法访问。
        
    - 避免命名冲突，实现封装。
        
- **示例**：
    
    ```C
    // File1.c
    static int hidden = 42; // 仅File1.c可访问
    static void hiddenFunc() { ... } // 仅File1.c可调用
    
    // File2.c
    extern int hidden; // 错误！无法访问File1.c的hidden
    ```
    
      

---
### **二、C++语言中的**`static`**（额外用途）**

#### 1. **修饰类的成员变量（静态成员变量）**

- **作用**：变量**属于类本身**，而非类的某个对象。
    
- **特点**：
    
    - 所有对象共享同一份静态成员变量。
        
    - 必须在类外单独初始化（分配内存）。
        
- **示例**：
    
    ```C++
    class MyClass {
    public:
        static int sharedVar; // 声明
    };
    int MyClass::sharedVar = 0; // 类外初始化
    
    int main() {
        MyClass obj1, obj2;
        obj1.sharedVar = 10;
        cout << obj2.sharedVar; // 输出 10（共享）
    }
    ```
    
      
    

#### 2. **修饰类的成员函数（静态成员函数）**

- **作用**：函数**属于类本身**，而非对象。
    
- **特点**：
    
    - 可直接通过类名调用（无需对象）。
        
    - 只能访问**静态成员变量**或**其他静态函数**（无`this`指针）。
        
- **示例**：
    
    ```C++
    class MyClass {
    public:
        static void print() {
            cout << "Value: " << sharedVar; // 只能访问静态成员
        }
        static int sharedVar;
    };
    int MyClass::sharedVar = 0;
    
    int main() {
        MyClass::print(); // 直接通过类调用
    }
    ```

# 静态方法

## 再论this指针

在C++中，this指针是一个隐式定义的常量指针，它指向当前对象实例本身

### 1.基本概念
    

- 定义：`this` 是每个非静态成员函数（包括构造函数）中自动可用的指针
    
- 类型：`ClassName *const this`（指向当前类的常量指针）
    
- 作用：指向当前调用成员函数的对象实例
    
- 访问：成员函数中隐含可用，无需声明
    

```Java
class MyClass {
public:
    void printAddress() {
        cout << "对象地址: " << this << endl;
    }
};

int main() {
    MyClass obj;
    obj.printAddress();  // 输出 obj 的地址
}
```

### 2.作用
    

#### (1) 解决命名冲突

当成员变量与局部变量同名时，用 `this->` 明确指定成员：

```C++
class Person {
    string name;  // 成员变量
public:
    void setName(string name) 
    {
        this->name = name;  // this->name 表示成员变量
    }
};
```

  

#### (2) 实现链式调用

返回 `*this` 支持连续调用：

```C++
class Counter {
    int count = 0;
public:
    Counter& increment() {
        count++;
        return *this;  // 返回当前对象
    }
    Counter& reset() {
        count = 0;
        return *this;
    }
};

// 链式调用
Counter c;
c.increment().increment().reset();
```

#### (3) 对象自引用

在成员函数中需要传递当前对象时：

```C++
class Node {
public:
    void linkTo(Node& other) {
        other.previous = this;  // 传递当前对象指针
    }
};
```

---

3. ### 关键特性
    

#### (1) 隐式存在

编译器自动为每个非静态成员函数添加 `this` 参数：

```C++
// 编译器转换示例
void printAddress(MyClass *const this);  // 实际函数签名
obj.printAddress();                     // 实际调用：printAddress(&obj);
```

#### (2) 常量性

- 在普通成员函数中：`MyClass *const this`（指针不可修改）
    
- 在 `const` 成员函数中：`const MyClass *const this`（指向的对象不可修改）
    

```C++
class Box {
    int width;
public:
    void setWidth(int w) 
    { 
        this->width = w; 
    }  // 允许修改
    
    int getWidth() const 
    {
        // this->width = 10; // 错误！const 成员函数中不能修改
        return this->width;
    }
};
```

#### (3) 生命周期

- 与对象生命周期相同
    
- 对象销毁后（如在析构函数中）仍可使用，但不能访问已销毁成员
    

  

4. ### 使用限制
    

5. 不能用于静态成员函数：
    

```C++
class Example {
public:
    static void func() {
        // this; // 错误！静态函数没有 this 指针
    }
};
```

2. 不能修改指针本身：
    

```C++
class Test {
public:
    void tryChange() {
        // this = nullptr; // 错误！this 是常量指针
    }
};
```

3. 不能取地址：
    

```C++
&this; // 错误！this 是右值
```

---

每当我们调用一个方法的时候，this指针都会随着你提供的输入参数传递给年那个方法

正是因为如此，我们才能在方法里像使用一个局部变量那样使用this指针

因为静态方法不是属于某个特点的对象，而是由全体对象共享的，这就意味着他们无法访问this指针，所以我们无法在静态方法里访问非静态的成员
