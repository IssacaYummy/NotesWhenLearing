我们可以把一个对象赋值给一个类型与之相同的变量

编译器将生成必要的代码把源对象各属性的值分别赋给目标对象的对应成员 。这种赋值行为称之为逐位复制（bitewise copy）

这种行为在绝大多数场合都没问题，但如果某些成员变量是指针的话，对象成员进行逐位复制的结果是会拥有两个一模一样的实例，而这两个副本里的同名指针会指向相同的地址

于是，当删除其中一个对象时，它包含的指针也将被删除，但万一此时另一个副本（对象）还在引用（或同时删除）这个指针，就会出现问题

我们可以通过重载赋值操作符，在其中对指针变量进行处理

`MyClass &operator=(const MyClass &rhs)`

该方法的输入参数为MyClass类型的、不可改变的引用

这里传入的参数是一个引用，所以编译器在传递输入参数时就不会再为它创建另外一个副本（否则可能导致无限递归）

由因为这里只需要读取这个输入参数，而不是改变它的值，所以我们用const把那个引用声明为一个常量

返回一个引用，该引用指向一个MyClass对象，好处是我们可以把一组赋值语句串起来。如：`a = b = c`

代码示例：

```C++
#include <iostream>
#include <string>

class MyClass
{
public:
    MyClass(int *p)
    {
        ptr = p;
    }
    ~MyClass()
    {
        delete ptr;
    }

    MyClass &operator=(const MyClass &rhs)
    {
        if(this != &rhs)
        {
            int *new_ptr = new int(*(rhs.ptr)); // Allocate and copy first
            delete ptr;                         // Then delete old data
            ptr = new_ptr;                      // Update pointer
        }
        else
        {
            std::cout << "Self-assignment detected.\n" << std::endl;
        }

        return *this;
    }

    void print()
    {
        std::cout << "Value:" << *ptr << std::endl;
        std::cout << "Address:" << ptr << std::endl;
    }
private:
    int *ptr;
};

int main()
{
    MyClass obj1(new int(1));
    MyClass obj2(new int(2));

    obj1.print();
    obj2.print();

    obj2 = obj1;

    obj1.print();
    obj2.print();

    return 0;
}
```

但只对赋值操作符重载还不能完美的解决问题

若将赋值部分的代码改写成

```C++
MyClass obj1;
MyClass obj2 = obj1;
```

后结果就不同了

刚才是先创建两个对象，然后再把obj1赋值给obj2，现在是先创建一个实例obj1，然后再创建实例obj2的同时使用obj1的值对它进行初始化

虽然看起来好像一样，但编译器却生成完全不同的代码：编译器会在MyClass类里寻找一个副本构造器（copy constructor），如果找不到，它会自行创建一个

所以即使我们对操作符进行了重载，编译器仍以逐位复制的方式把obj1赋值给obj2

要避开这个隐患，我们还需要自定义一个副本构造器

`MyClass( const MyClass &rhs)`

这个构造器需要一个固定不变的MyClass类型的引用作为输入参数，就像赋值操作符那样

构造器不需要返回类型

修改后的代码如下

```C++
#include <iostream>
#include <string>

class MyClass
{
public:
    MyClass(int *p)
    {
        std::cout << "into main constructkor\n" << std::endl;
        ptr = p;
        std::cout << "out of main constructkor\n" << std::endl;
    }
    MyClass(const MyClass &rhs)
    {
        std::cout << "into copy constructkor\n" << std::endl;
        *this = rhs; // Reuse assignment operator
        std::cout << "out of copy constructkor\n" << std::endl;
    }
    ~MyClass()
    {
        std::cout << "into deconstructor\n" << std::endl;
        delete ptr;
        std::cout << "out of deconstructor\n" << std::endl;
    }

    MyClass &operator=(const MyClass &rhs)
    {
        std::cout << "into assignment operrator\n" << std::endl;
        if(this != &rhs)
        {
            int *new_ptr = new int(*(rhs.ptr)); // Allocate and copy first
            delete ptr;                         // Then delete old data
            ptr = new_ptr;                      // Update pointer
        }
        else
        {
            std::cout << "Self-assignment detected.\n" << std::endl;
        }

        std::cout << "out of assignment operrator\n" << std::endl;

        return *this;
    }

    void print()
    {
        std::cout << "Value:" << *ptr << std::endl;
        std::cout << "Address:" << ptr << std::endl;
    }
private:
    int *ptr;
};

int main()
{
    MyClass obj1(new int(1));
    MyClass obj2(new int(2));
    obj2 = obj1;
    obj1.print();
    obj2.print();

    std::cout << "------------------" << std::endl;
    
    MyClass obj3(new int(3));
    MyClass obj4 = obj3;
    obj3.print();
    obj4.print();

    std::cout << "------------------" << std::endl;

    MyClass obj5(new int(5));
    obj5 = obj5;
    obj5.print();

    return 0;
}
```
