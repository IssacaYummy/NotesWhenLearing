### 联合（union）
联合与结构有很多相似之处，联合也可以容纳多种不同类型的值，但他每次只能储存这些值中的某一个

我们只能联合中的任意一个成员赋值，若对另一个成员赋值，则上一次被赋值的成员中的值会被丢弃

```C++
union password
{
    usigned long birthday;
    usigned short ssn;
    char* pet;
};

int main()
{
    password password1;
    password1.birthday = 0314;
    password1.ssn = 0618;
    password1.pet = “cookie”;
    
    return 0;
}
    
```

上述代码中的变量password1最终只有成员pet被赋值

### 枚举（enum）
枚举类型用来创建一个可取值的列表

```C++
enum weekdays 
{Monday, Tuesday, Wednesday, Thursday, Friday};
```

定义一个枚举类型之后，可以像下面这样创建该类型的变量

```C++
weekdays today;
```

然后像下边的方式对他进行赋值

```C++
today Thursday;
```

更详细的内容见C语言笔记
