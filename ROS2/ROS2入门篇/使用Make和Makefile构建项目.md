## Make

Make是通过读取一个叫做makefile的文件中定义的规则来执行构建的过程的

makefile类似于Maven工程中的pom.xml文件或者前端Node.js项目中的package.json文件

Makefile虽然最初是为C语言项目设计的，但它实际上是一个通用的构建工具，可以用来构建任何类型的项目，但目前主要用于C/C++项目中

Makefile由一系列的规则组成，每个规则包含了目标、依赖和命令

![[Pasted image 20260126151109.png]]

目标：我们要生成的文件

依赖：生成目标文件需要的文件

命令：生成这个文件的具体步骤

规则其实就是告诉make两件事，文件的依赖是什么，以及如何生成目标文件

在目录中新建名字为makefile的文件来编写规则

该文件首字母可以大写也可以小写，但不能有拓展名

![[Pasted image 20260126151120.png]]

注意命令前必须是tab不能是空格

这个规则的意思是如果我们要生成hello这个可执行文件的话，它会先检查main.c和message.c这两个文件是否有更新，如果有更新就会执行下面的命令来编译这两个文件，重新生成可执行文件hello

当我们再次执行make时，它会检查目标文件和依赖文件的时间戳。如果依赖文件的时间戳比目标文件新，也就是依赖文件有更新的话，就会执行命令来重新生成目标文件；否则就会跳过这个规则而不执行任何操作

在实际项目中，更规范和实际的做法是把编译和链接分开来写

也就是先把main.c和message.c分别编译为main.o和message.o，再把他们链接成hello这个可执行文件

Makefile定义了一系列规则，每个规则在满足依赖文件的前提下执行命令，就能创建出一个目标文件，这就是英文Make file的意思。把默认执行的规则放第一条，其他规则的顺序是无关紧要的，因为make执行时自动判断依赖。

有的时候我们可能会需要执行一些并不生成文件的操作，比如清理临时文件，生成文档，打包等等

这个时候就可以使用伪目标来定义这些规则

伪目标就是一个不生成文件的目标，只是一个标签，用来执行一定的操作

最常用的标签是clean，用来清理编译过程中生成的临时文件或者可执行文件

在makefile末尾加上clean标签并写上清理所有.o文件和hello文件的命令

执行的时候就可以在make后面加上这个标签，这样make就会删除所有的.o文件和hello文件

![[Pasted image 20260126151142.png]]

注意：如果我们本地有一个名字为clean的文件的话，make clean这个命令就会失效，因为make会把clean当作文件名来处理

应对方法就是在makefile里前面添加一个.PHONY,来告诉make，clean不是文件而是为目标

![[Pasted image 20260126151151.png]]

除了clean外还有一个常用的伪目标是all

当我们执行make时，make会默认执行第一条规则，但是如果我们想要生成的目标文件不止一个的话，就可以使用all这个伪目标

默认情况下make会把执行的命令行打印到终端上，如果不想的话我们可以在命令前加上@

在makefile中还可以定义变量，比如在编译时经常会用到一些编译选项，一般会把这些编译选项定义成一个变量，这样在后面的编译命令里就可以直接使用这个变量

![[Pasted image 20260126151156.png]]

使用变量的方法是$加上一对小括号，里面加上变量名

在正式工程文件中一般也都会把目标文件，源文件，中间文件等等都定义成变量

在makefile中还有一种特殊的变量叫做自动变量，它们是make在执行命令时会自动设置的一些变量，一般是以美元符号加上特殊字符来表示

|   |   |
|---|---|
|$@|目标文件|
|$<|第一个依赖文件|
|$^|所有依赖文件|

makefile中还可以通过通配符来简化规则，把相似的两个规则合并成一个

比如可以加上-f参数来指定makefile的名字

## CMake

CMake是一个跨平台的构建工具，可以根据不同的平台和编译器生成对应的构建文件

CMake 的配置文件是一个叫做CMakeLists.txt的文件

![[Pasted image 20260126151205.png]]

按照CMake的语法编写CMakeLists.txt文件，然后我们可以创建一个build文件夹，在里面执行cmake ..命令，这个命令的意思是在当前目录下生成构建文件，可以看到生成了makefile文件

![[Pasted image 20260126151209.png]]

然后就可以使用make命令构建文件了
