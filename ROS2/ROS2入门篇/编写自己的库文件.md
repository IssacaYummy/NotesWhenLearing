什么是库文件？一个库文件往往是许多算法，程序的集合，例如OpenCV库提供了许多计算机视觉相关的算法，Eigen库提供了矩阵代数的运算。
在Linux系统中，库文件分为静态库和动态库（共享库），分别以.a和.so结尾，所有库都是一些函数的集合，他们的区别是：静态库每次调用都会生成一个副本，而动态库只有一个副本
下面是一个源程序
```cpp
#include <iostream>
void printHello()
{
std::cout << "Hello SLAM!"<< std::endl;
}
```
如果想要将其编译为库文件， `CMakeLists.txt`文件应该写成如下格式
静态库：
```CMakeLists
cmake_minimum_required(VERSION 2.8)

project(libHelloSLAM)

add_library(HelloSLAM libHelloSLAM.cpp)
```
动态库：
```CMakeLists
cmake_minimum_required(VERSION 2.8)

project(libHelloSLAM)

add_library(HelloSLAM_shared SHARED libHelloSLAM_shared.cpp)
```
此时在build文件夹中就能看到我们编译好的.a或者.so文件

库文件本质为二进制文件，想要让别人（或自己）能够使用这个库，还需要编写相应的头文件，说明库文件中都有些什么，以及该如何使用，例如`libHelloSLAM.h`文件可以写成
```cpp
#ifndef LIBHELLOSLAM_H
#define LIBHELLOSLAM_H

void printHello();

#endif // LIBHELLOSLAM_H
```
然后在我们自己的程序中可以调用这个库文件中的函数
```cpp
#include "libHelloSLAM.h"

int main()
{
printHello();
return 0;
}
```
在`CMakeLists.txt`文件中链接使用到的库文件，并生成可执行程序
```CMakeLists
add_executable(useHello useHello.cpp)
target_link_libraries(useHello HelloSLAM)
```
