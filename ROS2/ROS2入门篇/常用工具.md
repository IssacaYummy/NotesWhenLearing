# 启动工具-Launch脚本

**launch文件允许我们同时启动和配置多个包含 ROS 2 节点的可执行文件**，建议使用python编写launch文件
## 1. 创建功能包，并添加/launch目录和.launch.py脚本

```bash
mkdir -p chapt5/chapt5_ws/src
cd chapt5/chapt5_ws/src
ros2 pkg create robot_startup --build-type ament_cmake --destination-directory src
mkdir -p src/robot_startup/launch
touch src/robot_startup/launch/example_action.launch.py
```

## 2. 启动多个结点的示例

需要导入LaunchDescription（用于对luanch文件内容进行描述）和Node（用于声明结点所在位置）库

注意这里要定义一个名字叫做generate_launch_description的函数，ROS2会对该函数名字做识别

```python
# 导入库
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    """launch内容描述函数，由ros2 launch 扫描调用"""
    action_robot_01 = Node(
        package="example_action_rclcpp",
        executable="action_robot_01"
    )
    action_control_01 = Node(
        package="example_action_rclcpp",
        executable="action_control_01"
    )
    # 创建LaunchDescription对象launch_description,用于描述launch文件
    launch_description = LaunchDescription(
        [action_robot_01, action_control_01])
    # 返回让ROS2根据launch描述执行节点
    return launch_description
```

## 3. 将launch文件拷贝到安装目录

ament_cmake 类型功能包在CMakeLists.txt文件中添加下面一行
```CMakeLists
install(DIRECTORY launch
  DESTINATION share/${PROJECT_NAME})
```

# 数据录播工具-rosbag2

rosbag2用于记录话题的数据，我们可以使用这个指令将话题的数据存储为文件，后续我们无需启动节点，直接可以将bag文件里的话题数据发布出来

## 常用指令

```bash
ros2 run demo_nodes_cpp talker # 运行talker节点

ros2 bag record /topic_name # 记录一个话题

ros2 bag rocord topic_name1 topic_name2 # 记录多个话题

ros2 bag record -a  # 记录所有话题

ros2 bag record -o file-name topic_name # 指定输出文件名称

ros2 bag record -s file-type topic_name # 指定输出文件格式，目前只支持sqllite3

ros2 bag info bag-file # 查看录制话题的信息

ros2 bag play xxx.db3 # 播放录制的话题

ros2 bag play xxx.db3 -r 10 # 以10倍速度播放

ros2 bag play xxx.db3 -l # 循环播放

ros2 bag play xxx.db3 --topics /topic_name # 播放单个话题

```

# 仿真工具-Gazebo

安装gazebo：

```bash
sudo apt install gazebo
```

安装两轮差速功能包

```bash
sudo apt install ros-humble-gazebo-*
```

运行两轮差速demo：

```bash
gazebo /opt/ros/humble/share/gazebo_plugins/worlds/gazebo_ros_diff_drive_demo.world

```

查看话题计类型
```bash
ros2 topic list -t
```

使用下面的命令让车子动起来
```bash
ros2 topic pub /demo/cmd_demo geometry_msgs/msg/Twist "{linear: {x: 0.2,y: 0,z: 0},angular: {x: 0,y: 0,z: 0}}"
```
